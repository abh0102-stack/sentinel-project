# 센티넬 영상편집 키트 v1

작성일: 2026-10-10
목표: 촬영 → 편집 → 업로드를 **1편당 60분 이내**로 끝내는 반복 시스템.
원칙: 특정 사건·내부 업무 언급 없음 / 개인 의견·일반 안전 수칙 중심.

## 1. 폴더 구조

```
video/
├── README.md                 ← 이 문서 (워크플로·규칙)
├── CHECKLIST.md              ← 촬영/편집/업로드 체크리스트
├── tools/
│   └── sentinel_short.sh     ← 원본 → 쇼츠 완성본 자동 변환 (9:16·자막·음량)
└── shorts/
    ├── S01_night_walk/       ← 밤길 안전 3초 루틴
    ├── S02_followed/         ← 누가 따라올 때
    └── S03_defense_order/    ← 자기방어의 순서
        ├── script.md         ← 대본·샷리스트·타임라인
        └── subs.srt          ← 자막 (그대로 사용 가능)
```

촬영 원본은 저장소에 올리지 않습니다(용량). 휴대폰/PC의 같은 이름 폴더에 보관하세요.

## 2. 파일 이름 규칙

`S{번호}_{주제}_{버전}.mp4` → 예: `S01_night_walk_raw.mp4`, `S01_night_walk_final.mp4`

## 3. 표준 사양 (유튜브 쇼츠 · 인스타 릴스 · 틱톡 공통)

| 항목 | 값 |
|---|---|
| 해상도 | 1080 × 1920 (9:16) |
| 프레임 | 30fps |
| 길이 | 20~45초 (첫 2초 안에 훅) |
| 음량 | -14 LUFS (플랫폼 권장 수준) |
| 자막 | 화면 중앙 하단, 한 줄 14자 이내, 흰 글씨 + 검은 테두리 |
| 안전 영역 | 상단 250px·하단 400px에는 핵심 글자 배치 금지(UI에 가려짐) |

## 4. 1편 60분 워크플로

1. **촬영 (15분)** — `script.md`의 샷리스트대로. 세로 촬영, 4K/1080p 30fps, 컷마다 2초 여유.
2. **컷 편집 (20분)** — CapCut(모바일/PC 무료)에서 타임라인대로 자르기. 말 사이 공백 제거.
3. **자막 (5분)** — `subs.srt` 불러오기(CapCut: 텍스트 → 자막 가져오기) 또는 아래 스크립트로 자동 입히기.
4. **마무리 (10분)** — 효과음 1~2개, 배경음 -25dB 이하, 마지막 2초 CTA.
5. **업로드 (10분)** — `CHECKLIST.md` 업로드 항목 확인 후 3개 플랫폼 동시 게시.

## 5. 자동 변환 스크립트 (PC에서 ffmpeg 사용 시)

```bash
# 원본(가로/세로 무관) → 1080x1920, 자막 번인, 음량 -14 LUFS 정규화
./video/tools/sentinel_short.sh 원본.mp4 video/shorts/S01_night_walk/subs.srt S01_night_walk_final.mp4

# 자막 없이 세로 변환 + 음량만
./video/tools/sentinel_short.sh 원본.mp4 - S01_night_walk_final.mp4
```

필요 프로그램: ffmpeg (Windows: `winget install ffmpeg`, Mac: `brew install ffmpeg`).
자막 폰트 기본값은 `Noto Sans CJK KR` → 없으면 `FONT="맑은 고딕"` 처럼 환경변수로 지정.

## 6. 우선순위
