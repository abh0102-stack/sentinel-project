# 촬영 · 편집 · 업로드 체크리스트

## 촬영 전
- [ ] 휴대폰 저장공간 10GB 이상, 배터리 80% 이상
- [ ] 세로 모드, 렌즈 닦기, 30fps 고정
- [ ] 마이크(유선/무선 핀마이크) 연결 확인 — 소리가 화질보다 중요
- [ ] 의상: 셔츠 + 조끼 (센티넬 시그니처)
- [ ] 촬영 장소 허가 / 지나가는 행인·차량 번호판 얼굴 안 나오게

## 편집 중
- [ ] 첫 2초: 질문 또는 강한 문장으로 시작 (인사·자기소개 금지)
- [ ] 3초마다 화면 변화 (컷·줌·자막 강조)
- [ ] 자막 오탈자 확인, 한 줄 14자 이내
- [ ] 배경음 저작권 확인 (YouTube 오디오 보관함 / CapCut 상업용 라이선스 음원)
- [ ] 마지막 2초 CTA: "저장해두고 가족에게 보내주세요"

## 업로드 전 (리스크 관리)
- [ ] 특정 사건·피해자·대상자 언급 없음
- [ ] 소속 기관명·내부 업무·근무지 노출 없음 (배경·명찰·서류 확인)
- [ ] "개인 의견이며 일반 안전 수칙입니다" 문구 설명란 포함
- [ ] 폭력 재연은 과장 없이, 실제 타격 장면 없음 (플랫폼 정책)
- [ ] 겸직·외부활동 관련 규정 확인 완료 (수익 발생 전 필수)

## 업로드
- [ ] 제목: 30자 이내, 상황 + 해결 (예: "밤길에 누가 따라올 때 3초 루틴")
- [ ] 해시태그 3~5개: #자기방어 #안전 #밤길 #생활안전 #센티넬
- [ ] 유튜브 쇼츠 · 인스타 릴스 · 틱톡 동시 게시
- [ ] 쓰레드에 같은 주제 글 + 영상 링크 연결
- [ ] 48시간 후 조회수·시청 지속률 기록
